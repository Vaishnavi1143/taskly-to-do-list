# Taskly — To-Do List & Task Manager

A responsive mini website built with HTML, CSS and JavaScript.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks: All, Active and Completed
- Clear all completed tasks
- Save tasks in browser `localStorage`
- Task summary showing total, completed and remaining tasks
- Responsive layout for mobile and desktop

## How to run
1. Download or extract this project folder.
2. Open `index.html` in a web browser.
3. Add a task using the input box.
4. Refresh the page: saved tasks will still be there because the project uses `localStorage`.

## Files
- `index.html` — page structure
- `style.css` — design and responsive styling
- `script.js` — task functionality and localStorage

No installation or server is required.
